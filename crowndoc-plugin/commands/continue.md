# /crowndoc:continue

Resume the crowndoc workflow from the current state, automatically detecting what work is in progress.

---

## Purpose

This is the primary entry point for continuing crowndoc work. It:
1. Reads all LIVE documents to determine current state
2. Detects which workflow (if any) is active
3. Identifies the current phase/task
4. Resumes execution from exactly where work was interrupted
5. Maintains all cross-references and version integrity

Use this command when:
- Returning to work after a break
- Resuming after context switch
- Unsure what the next step should be
- Starting a new session on existing crowndoc project

---

## State Detection Logic

### Priority Order

1. **SD Workflow** (highest priority)
   - If SD.md status is NOT "ready" or "complete"
   - SD phases take precedence over TODO tasks
   
2. **TODO Workflow**
   - If TODO.md has unchecked tasks (`[ ]`)
   - Work on pending tasks in order
   
3. **Clean State** (lowest priority)
   - No active workflow
   - Ready for new work or new SD pass

### Why SD Takes Priority

The SD workflow involves systematic codebase review. Interrupting it mid-phase can:
- Leave findings undocumented
- Create incomplete cross-references
- Miss integration opportunities

Therefore, SD phases should complete before switching to TODO tasks (unless the TODO was generated BY the SD pass).

### Step 3: Determine Active Workflow

```python
def determine_active_workflow(todo_state, sd_state):
    """
    Determine which workflow is currently active.
    Returns: (workflow_type, workflow_details)
    """
    
    # Check SD first (higher priority)
    if sd_state:
        status = sd_state["status"].lower()
        
        # Status indicates active SD workflow
        active_statuses = [
            "recon complete",
            "scanning",
            "flagging",
            "resolving",
            "verifying",
            "in progress"
        ]
        
        if any(s in status for s in active_statuses):
            return ("SD", {
                "phase": sd_state["current_phase"],
                "quadrant": sd_state.get("current_quadrant"),
                "status": sd_state["status"],
                "findings": sd_state["findings"]
            })
        
        # Check if partial quadrant completion
        completed = sum(1 for q in sd_state["quadrants"].values() 
                       if q["status"] == "COMPLETE")
        if 0 < completed < 4:
            next_q = next(q for q, data in sd_state["quadrants"].items() 
                         if data["status"] != "COMPLETE")
            return ("SD", {
                "phase": "S",
                "quadrant": next_q,
                "status": f"ready to scan {next_q}",
                "findings": sd_state["findings"]
            })
    
    # Check TODO
    if todo_state and todo_state["pending_tasks"]:
        return ("TODO", {
            "version": todo_state["version"],
            "pending": todo_state["pending_tasks"],
            "next_task": todo_state["next_task"],
            "completed": todo_state["completed_tasks"]
        })
    
    # Check if TODO version needs archiving
    if todo_state and todo_state["completed_tasks"] and not todo_state["pending_tasks"]:
        return ("TODO_ARCHIVE", {
            "version": todo_state["version"],
            "completed": todo_state["completed_tasks"]
        })
    
    # Nothing active
    return ("NONE", {
        "todo_version": todo_state["version"] if todo_state else "N/A",
        "sd_status": sd_state["status"] if sd_state else "N/A"
    })

active_workflow, details = determine_active_workflow(todo_state, sd_state)
```

### Step 5: Resume Appropriate Workflow

#### Case A: SD Workflow Active

```python
if active_workflow == "SD":
    phase = details["phase"]
    quadrant = details.get("quadrant")
    
    print(f"""
Resuming SD workflow...

Current phase: SD:{phase} {quadrant if quadrant else ''}
Status: {details['status']}
""")
    
    # Determine exact resume point
    if phase == "R":
        print("Recon phase was interrupted.")
        print("Resuming SD:R...")
        # Execute SD:R
        execute_sd_recon()
        
    elif phase == "S":
        print(f"Scan phase for {quadrant} was interrupted.")
        # Check if any files already scanned
        scanned = get_scanned_files(sd_content, quadrant)
        remaining = get_remaining_files(sd_content, quadrant, scanned)
        
        if remaining:
            print(f"Files remaining in {quadrant}: {len(remaining)}")
            print(f"Resuming SD:S {quadrant}...")
            # Continue scanning
            execute_sd_scan(quadrant, start_from=remaining)
        else:
            print(f"All files in {quadrant} scanned.")
            print("Proceeding to SD:F...")
            execute_sd_flag()
    
    elif phase == "F":
        print("Flag phase was interrupted.")
        print("Resuming SD:F...")
        execute_sd_flag()
    
    elif phase == "X":
        print("Resolve phase was interrupted.")
        # Check which findings are already resolved
        unresolved = get_unresolved_findings(sd_content)
        print(f"Unresolved findings: {len(unresolved)}")
        print("Resuming SD:X...")
        execute_sd_resolve(unresolved)
    
    elif phase == "V":
        print("Verify phase was interrupted.")
        print("Resuming SD:V...")
        execute_sd_verify()
```

## State Transitions

### SD Workflow States

```
READY → SD:R → RECON_COMPLETE
                    ↓
              SD:S Q1 → Q1_SCANNED
                            ↓
              SD:S Q2 → Q2_SCANNED
                            ↓
              SD:S Q3 → Q3_SCANNED
                            ↓
              SD:S Q4 → Q4_SCANNED
                            ↓
                        SD:F → FLAGGED
                                ↓
                            SD:X → RESOLVED
                                    ↓
                                SD:V → VERIFIED
                                        ↓
                                    COMPLETE
```

### TODO Workflow States

```
EMPTY → Tasks Added → ACTIVE
                        ↓
              Task 1 Complete → ACTIVE (less pending)
                                ↓
              Task N Complete → ALL_COMPLETE
                                    ↓
                                ARCHIVED → EMPTY (next version)
```

### Continue Detection Matrix

| SD Status | TODO Status | Continue Action |
|-----------|-------------|-----------------|
| READY | Pending tasks | Resume TODO |
| RECON_COMPLETE | Any | Resume SD:S Q1 |
| SCANNING Qn | Any | Resume SD:S Qn |
| FLAGGED | Any | Resume SD:X |
| RESOLVED | Any | Resume SD:V |
| COMPLETE | Pending tasks | Resume TODO |
| COMPLETE | All complete | Archive TODO |
| READY | Empty | Offer choices |

## Edge Cases

### Conflicting States

If documents are in inconsistent states:

```python
# Example: SD says "resolving" but no findings exist
if sd_state["status"] == "resolving" and sd_state["findings"]["total"] == 0:
    print("""
⚠️ Inconsistent state detected

SD.md indicates "resolving" phase but no findings recorded.
This may indicate interrupted or incomplete scan phase.

Options:
1. Reset SD phase to scanning and re-scan
2. Mark SD pass as complete (no findings)
3. Manual inspection needed

Select: _
""")
```

### Missing Documents

```python
if documents["VALIDATION.md"] is None:
    print("""
⚠️ VALIDATION.md not found

This document is required for verification tracking.
Creating from template...
""")
    create_validation_md()
```

```python

    todo_state = parse_todo_state(documents["TODO.md"])

Error: {e}

The document may be corrupted or have invalid format.

Options:
1. View raw content
2. Reset to clean template
3. Manual repair needed

Select: _
""")
```

## Integration Points

### Pre-Continue Checks

Before resuming any workflow:
1. Validate cross-references
2. Check for uncommitted changes
3. Verify file permissions
4. Confirm archive directories exist

### Post-Continue Actions

After each workflow step:
1. Update all affected documents
2. Create new cross-references
3. Report changes made
4. Suggest next step

---

## Best Practices

### DO

- Use `crowndoc: continue` as default entry point
- Let the system detect appropriate workflow
- Complete phases before switching workflows
- Review state summary before proceeding

### DON'T

- Manually modify documents mid-workflow
- Switch workflows without completing phases
- Ignore state warnings
- Skip cross-reference creation
