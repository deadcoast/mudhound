# MUDHOUND - Design Specification v1.0

> Batch URL extraction from keyword searches via terminal interface.

| Layer | Purpose | Modularity Hook |
|-------|---------|-----------------|
| Presentation | Frame rendering, themes, layout | Theme files, border sets |
| Interaction | Menus, prompts, validation | Component registry |
| Command | Typer commands | Subcommand plugins |
| Core | Search orchestration, storage | Engine interface |
| Adapter | Search engine implementations | `SearchAdapter` ABC |

> The system supports dynamic terminal resize with min 60-col graceful degradation.
> All glyphs are ASCII-safe with unicode optional. Adapter interface is generator-based for streaming results.

#### 3.1.3 Dynamic Resize Handling

```python
class LayoutManager:
    """
    Manages terminal dimensions and triggers re-renders on resize.
    
    RESIZE STRATEGY:
    1. Poll terminal size on each render call
    2. Compare against cached dimensions
    3. If changed: recalculate all frame widths, re-wrap content
    4. Emit resize event to registered components
    
    MINIMUM DIMENSIONS:
    - Width:  60 columns (graceful degradation below)
    - Height: 10 rows (scroll mode activated below)
    """
    
    MIN_WIDTH = 60
    MIN_HEIGHT = 10
    PADDING_H = 2  # Left + right padding inside frames
    PADDING_V = 1  # Top + bottom padding inside frames
    
    def get_content_width(self) -> int:
        """Returns usable width inside frame borders."""
        term_width = shutil.get_terminal_size().columns
        return max(term_width - 4, self.MIN_WIDTH - 4)  # 2 borders + 2 padding
```

### 5.2 Command Examples

```bash
# Basic search
qh search "python web scraping"

# Search with options
qh search "machine learning" --max 100 --format json --output results.json

# Quiet mode for scripting
qh search "api endpoints" -q -f urls > urls.txt

# Interactive mode
qh search "data science" --interactive

# Pipe-friendly
echo "search term" | qh search --stdin

# Configuration
qh config set default.max_results 100
qh config set theme hacker
qh config list

# History
qh history list --limit 10
qh history replay 42
qh history clear --confirm
```

## 7. ADAPTER INTERFACE SPECIFICATION

### 7.1 Base Adapter Protocol

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Iterator, Optional

@dataclass
class SearchResult:
    """Individual search result."""
    url: str
    title: str
    snippet: str
    source: str
    rank: int
    metadata: dict = field(default_factory=dict)

@dataclass  
class SearchOptions:
    """Search configuration options."""
    max_results: int = 50
    region: str = "wt-wt"
    safesearch: str = "moderate"
    time_limit: Optional[str] = None  # d, w, m, y

class SearchAdapter(ABC):
    """
    Abstract base class for search engine adapters.
    
    All adapters must implement this interface to be registered
    with the adapter registry.
    """
    
    @property
    @abstractmethod
    def name(self) -> str:
        """Unique adapter identifier."""
        pass
    
    @property
    @abstractmethod
    def display_name(self) -> str:
        """Human-readable name."""
        pass
    
    @abstractmethod
    def search(
        self, 
        query: str, 
        options: SearchOptions
    ) -> Iterator[SearchResult]:
        """
        Execute search and yield results.
        
        Must be a generator for streaming support.
        """
        pass
    
    @abstractmethod
    def validate_options(self, options: SearchOptions) -> list[str]:
        """
        Validate options for this adapter.
        
        Returns list of validation error messages (empty = valid).
        """
        pass
    
    def on_rate_limit(self) -> float:
        """
        Called when rate limit detected.
        
        Returns: seconds to wait before retry
        """
        return 2.0
```

### 7.2 Adapter Registry

```python
class AdapterRegistry:
    """
    Discovers and manages search adapters.
    
    DISCOVERY:
    1. Built-in adapters (mudhound.adapters.*)
    2. Plugin adapters (mudhound_adapter_* packages)
    3. User adapters (~/.mudhound/adapters/*.py)
    """
    
    _adapters: dict[str, Type[SearchAdapter]] = {}
    
    @classmethod
    def register(cls, adapter_cls: Type[SearchAdapter]) -> None:
        """Register an adapter class."""
        instance = adapter_cls()
        cls._adapters[instance.name] = adapter_cls
    
    @classmethod
    def get(cls, name: str) -> SearchAdapter:
        """Get adapter instance by name."""
        if name not in cls._adapters:
            raise AdapterNotFoundError(name)
        return cls._adapters[name]()
    
    @classmethod
    def list_available(cls) -> list[str]:
        """List all registered adapter names."""
        return list(cls._adapters.keys())
```

### 9.1 Core Models

```python
from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional
from enum import Enum

class SearchStatus(Enum):
    PENDING = "pending"
    RUNNING = "running"
    COMPLETE = "complete"
    FAILED = "failed"
    CANCELLED = "cancelled"

@dataclass
class SearchQuery:
    """Represents a search request."""
    id: str
    query: str
    engine: str
    options: SearchOptions
    created_at: datetime
    status: SearchStatus = SearchStatus.PENDING

@dataclass
class SearchSession:
    """Complete search session with results."""
    query: SearchQuery
    results: list[SearchResult] = field(default_factory=list)
    started_at: Optional[datetime] = None
    completed_at: Optional[datetime] = None
    error: Optional[str] = None
    
    @property
    def duration(self) -> Optional[float]:
        if self.started_at and self.completed_at:
            return (self.completed_at - self.started_at).total_seconds()
        return None
    
    @property
    def result_count(self) -> int:
        return len(self.results)
```
